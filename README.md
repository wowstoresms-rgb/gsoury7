# منصة جسور المباشرة | Josour Live

منصة ويب متجاوبة لعرض البيانات اللحظية بمقاس الستوري والريلز (`9:16`) مع حركة موشن جرافيك وتصدير مباشر للصور والفيديو بشعار المنصة.

## الملفات
- `index.html`: الواجهة الرئيسية للمنصة (الدولار في البنوك، العملات، الذهب، الأرصاد والطاقة النظيفة، التعداد السكاني، الحرم المكي).
- `haram-live.html`: صفحة مستقلة للبث المباشر للحرم المكي بجودات ومصادر متعددة.
- `manifest.json` و `sw.js`: دعم تطبيق الويب التقدمي (PWA).

## النشر على GitHub Pages
1. ارفع جميع الملفات في هذا المجلد إلى المستودع على GitHub.
2. من إعدادات المستودع (**Settings → Pages**)، اختر الفرع الرئيسي (`main`) والمجلد الجذر (`/root`).
3. احفظ الإعدادات ليتم نشر المنصة مباشرة.
